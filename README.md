# NovaMed Maintenance System

### Medical Equipment Maintenance Management | Python Project

NovaMed Maintenance System is a Python-based application designed to help organize medical equipment information and maintenance records.

The project was developed as part of **CS50's Introduction to Programming with Python (CS50P)**, offered by Harvard University.

## Project Overview

NovaMed provides a command-line interface for managing medical equipment and tracking preventive maintenance activities.

### Main Features

- Register new medical equipment.
- View and search equipment records.
- Register preventive and corrective maintenance.
- Review maintenance history.
- Calculate upcoming preventive maintenance dates.
- Identify equipment maintenance status as OK, DUE SOON, or OVERDUE.
- Store equipment and maintenance records using CSV files.

## Technologies Used

- Python
- CSV file handling
- Python `datetime` module
- Pytest
- Command-line interface (CLI)
